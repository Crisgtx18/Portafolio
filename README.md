# Portafolio Personal | Cristian Ginarte Cárdenas

Portafolio web personal de Cristian Ginarte Cárdenas, desarrollador web y electrónico autodidacta. De Cuba a Brasil, creando soluciones que conectan el mundo físico y digital.

---

## Descripción

Sitio web multipágina con diseño cyberpunk minimalista en negro y cyan, creado desde cero con HTML, CSS y JavaScript. Reúne mi presentación profesional, mis habilidades técnicas, mis proyectos y mis formas de contacto.

---

## Secciones

- Inicio: Presentación personal y accesos rápidos.
- Sobre mí: Biografía, formación y objetivos.
- Habilidades: Tecnologías y herramientas que manejo.
- Proyectos: Trabajos realizados con enlaces a GitHub.
- Contacto: Formas de contacto directo.

---

## Tecnologías utilizadas

- HTML5 para la estructura semántica.
- CSS3 para el diseño, las animaciones y los efectos neón.
- JavaScript (próximamente) para interacciones avanzadas.
- Git y GitHub para control de versiones.

---

## Características del diseño

- Fondo cyberpunk con cuadrícula sutil.
- Efectos de glow neón en títulos, botones y tarjetas.
- Halo radial cyan en todas las páginas.
- Transición suave al cambiar de página.
- Diseño responsive para móvil, tablet y PC.
- Navegación con indicador de página activa.
