# Portafolio Personal | Cristian Ginarte Cárdenas

Portafolio web personal de Cristian Ginarte Cárdenas, técnico en Automatización y desarrollador Python & Web. De Cuba a Brasil, construyendo juegos, herramientas de escritorio y sitios web.

**Ver en vivo:** https://crisgtx18.github.io/Portafolio/

---

## Descripción

Sitio web multipágina con diseño cyberpunk minimalista en negro y cyan, creado desde cero con HTML, CSS y JavaScript. Reúne mi presentación profesional, habilidades técnicas, proyectos y formas de contacto.

---

## Secciones

| Página | Contenido |
|---|---|
| `index.html` | Presentación y accesos rápidos |
| `sobre-mi.html` | Biografía, formación, experiencia y disponibilidad |
| `habilidades.html` | Tecnologías, herramientas, idiomas y qué estoy aprendiendo |
| `proyectos.html` | 12 proyectos con enlace a su repositorio |
| `contacto.html` | Email, WhatsApp, GitHub, LinkedIn y YouTube |

---

## Tecnologías utilizadas

- **HTML5** para la estructura semántica.
- **CSS3** para el diseño, las animaciones y los efectos neón.
- **JavaScript** para interacciones.
- **GitHub Pages** para el despliegue.
- **Git** para control de versiones.

---

## Características del diseño

- Fondo cyberpunk con cuadrícula sutil.
- Efectos de glow neón en títulos, botones y tarjetas.
- Halo radial cyan en todas las páginas.
- Diseño responsive para móvil, tablet y PC.
- Navegación con indicador de página activa.

## Sobre mí

Técnico medio en Automatización (Instituto Técnico Medio Osvaldo Herrera, La Habana, 2019–2022) con 2,5 años de Ingeniería Automática (CUJAE, 2024–2026) y dos años de servicio militar. Me radicé en Cruz das Almas, Brasil, en julio de 2026.

Hoy reparo computadoras y atiendo clientes en **Central Info**, donde también desarrollé el sitio web del taller. Antes trabajé en Gelma e ICRT, en 2M Gamer y como técnico eléctrico de vehículos.

Estudio Programación Web con IA en la UFRB y Consultoría Digital en la Prefeitura de Cruz das Almas.

Tecnologías con las que trabajo:

- **Python:** Pygame, Flet, SQLite, FastAPI, pyserial
- **Web:** HTML5, CSS3, JavaScript, Bootstrap, localStorage
- **Electrónica:** Arduino, Raspberry Pi, RPi.GPIO, Proteus
- **Otros:** C, C++, Blender, Git, VS Code
